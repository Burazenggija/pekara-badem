# Pekara Badem + Kafana Jedno Mesto

- `index.html` – sajt Pekare Badem
- `kafana-jedno-mesto.html` – sajt Kafane Jedno Mesto
- `assets/` – slike, logo i video

## Kako se objavljuje
Svaka izmena koja se sačuva (commit) na GitHub-u u granu `main`
automatski se objavljuje na Netlify-ju za oko 30 sekundi.
Ručno prevlačenje foldera više nije potrebno.

Uputstvo za formular "Posao" je u `UPUTSTVO.txt`.
